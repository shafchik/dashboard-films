# Archive — дашборд фильмов

## Тема и пользователь

Archive — личная картотека для зрителя, который хочет находить фильмы по жанру, стране, году и части названия, открывать случайные недавние релизы и собирать собственную полку избранного. Интерфейс рассчитан на самостоятельный просмотр на телефоне и компьютере.

## Виджеты

- **Поиск по архиву** — фильтры жанра и страны, диапазон лет, необязательная часть названия. Выдача содержит до 12 записей из открытого каталога. Поля и кнопки блокируются на время запроса; ответы старого запроса отбрасываются.
- **Находка из свежих релизов** — случайный фильм с датой выхода в пределах последних 365 дней. Каталог выбирает кандидата, затем отдельный сервис пытается получить краткое описание и миниатюру.
- **Моя полка** — сердечко сохраняет фильм в `localStorage`; список остаётся в том же браузере после перезагрузки страницы.

## Использованные API

### Wikidata Query Service (SPARQL)

Документация: [Wikidata Query Service — пользовательская документация](https://www.wikidata.org/wiki/Wikidata:SPARQL_query_service) и [SPARQL endpoint](https://query.wikidata.org/).

Пример запроса: [пример URL](https://query.wikidata.org/sparql?query=SELECT%20%3Ffilm%20%3FfilmLabel%20WHERE%20%7B%20%3Ffilm%20wdt%3AP31%20wd%3AQ11424.%20SERVICE%20wikibase%3Alabel%20%7B%20bd%3AserviceParam%20wikibase%3Alanguage%20%22en%22.%20%7D%20%7D%20LIMIT%201&format=json). В приложении запросы строятся по выбранным пользователем фильтрам.

Пример поля ответа: `results.bindings[].filmLabel.value` — подпись названия фильма в формате SPARQL JSON.

### Wikipedia REST API (описание случайного фильма)

Документация: [Wikimedia REST API](https://www.mediawiki.org/wiki/Wikimedia_REST_API) и [справочник REST API MediaWiki](https://www.mediawiki.org/wiki/API:REST_API/Reference).

Пример запроса: [summary страницы Parasite](https://en.wikipedia.org/api/rest_v1/page/summary/Parasite).

Пример поля ответа: `extract` — краткое текстовое описание страницы. Если REST API недоступен, найденный фильм всё равно отображается без описания.

Виджеты независимы: ошибка одного запроса отображается внутри его секции и не скрывает остальные. Сетевые ответы проверяются на HTTP-ошибку и ожидаемую структуру. Внешний текст вставляется как текст, а не как HTML.

## Запуск

Сборка и установка зависимостей не нужны. Открой PowerShell в папке `Web\3` и запусти локальный статический сервер:

```powershell
py -m http.server 8000
```

Открой `http://localhost:8000/` в браузере. Локальный HTTP-сервер предпочтительнее открытия `index.html` напрямую: браузеры могут ограничивать сетевые запросы со страниц `file://`.

## Ограничения

- Wikidata — открытая база с неполными и неодинаково размеченными данными. Для части фильмов отсутствуют жанр, страна, дата, подпись на русском или постер; состав выдачи может отличаться от привычных каталогов.
- Поиск ограничен 12 совпадениями и текущим набором жанров/стран в форме. Название ищется по подписи фильма и может не найти локализованный вариант.
- «Последние 365 дней» рассчитываются по датам Wikidata; не каждая дата релиза в базе подтверждена или означает премьеру в конкретной стране.
- Описание и изображение случайной находки загружаются из английской Википедии. Они могут отсутствовать, а её краткий текст может быть на английском.
- Сервисы могут отвечать медленно, временно быть недоступными или ограничивать частоту запросов. Для реального публичного продукта стоит учитывать их условия использования и кэширование.
- Избранное хранится только локально в браузере и не синхронизируется между устройствами. Если браузер запрещает хранилище или пользователь очищает его, список может пропасть.
- Шрифт Literata загружается с Google Fonts при наличии сети; при недоступности используется системный запасной шрифт.

## Полезные промпты для дальнейшей работы

1. «Добавь в Archive сортировку результатов поиска по дате и алфавиту. Сохрани мобильную сетку, управление клавиатурой и независимое состояние каждого API.»
2. «Сделай импорт и экспорт полки избранного в JSON через кнопки. Проверь некорректный файл и сохрани текущую полку при ошибке импорта.»
3. «Добавь фильтр по языку/стране релиза, если Wikidata позволяет надёжно получить эти данные; при нехватке данных явно покажи пустой результат и не подменяй его демонстрационными значениями.»
